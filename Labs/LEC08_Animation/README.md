# Drill #8. 애니메이션 뷰어

`animation_viewer.py` 를 이 폴더에서 실행 (VS Code에서 실행하면 자동으로 이 폴더에서 실행됨). ESC 또는 창 닫기로 종료.

## 사용한 Sprite Sheet

수업 자료의 `sonic-sprite.png` (399x525, Classic Sonic Sprites).
프레임이 격자에 맞춰 놓여 있지 않고 동작마다, 프레임마다 크기와 위치가 제각각인 시트이다.
각 프레임의 위치와 크기는 시트를 픽셀 단위로 확인해 `animations` 표에 `(left, top, width, height)` 로 정리했다.

## 구현 내용

| 애니메이션 | 동작 | 프레임 수 | 프레임 시간 |
| --- | --- | --- | --- |
| Idle | 발을 구르며 기다리기 | 4 | 0.15초 |
| Walk | 걷기 | 6 | 0.1초 |
| Run | 다리가 8자로 보이는 전력 질주 | 4 | 0.06초 |
| Spin | 몸을 말아 회전 | 8 | 0.05초 |
| Twirl | 제자리에서 한 바퀴 돌기 | 6 | 0.1초 |

- **재생 방식**: 화면 가운데에서 각 애니메이션을 5회 반복 → 마지막 프레임에서 1초 정지 → 다음 애니메이션.
  Twirl 다음에는 다시 Idle로 돌아가 무한 반복
- **확대**: 10배 확대. 서 있는 소닉 키 38픽셀 → 380픽셀로 화면 높이(600)의 절반 이상.
  정수 배율이라 픽셀이 뭉개지지 않음
- 화면 위쪽에 애니메이션 이름, 반복 횟수(loop n/5 / pause), 프레임 번호와 현재 프레임 크기 표시

## 추가 점수 항목

### 1. 프레임 크기가 프레임마다 달라지는 복잡한 Sprite Sheet 사용

| 애니메이션 | 프레임 폭 | 프레임 높이 |
| --- | --- | --- |
| Idle | 29 ~ 30 | 38 |
| Walk | 26 ~ 37 | 35 ~ 38 |
| Run | 38 ~ 39 | 31 ~ 32 |
| Spin | 29 ~ 31 | 29 ~ 31 |
| Twirl | 20 ~ 29 | 43 ~ 45 |

- 프레임마다 `(left, top, width, height)` 를 따로 저장하고, 그 크기대로 `clip_draw` 한다.
  시트 좌표는 왼쪽 위 기준으로 쟀기 때문에 `clip_draw`용 아래쪽 좌표로 `bottom = 시트높이 - top - height` 변환을 한다.
- 크기가 다른 프레임을 중심에 맞춰 그리면 캐릭터가 위아래로 들썩이므로,
  **프레임의 아래쪽 가운데(발밑)를 항상 같은 땅 위치에 맞춰** 그린다.
- 걷기는 다리를 뻗는 프레임일수록 폭이 넓어져서 몸통이 좌우로 밀린다.
  프레임마다 머리 위치를 재서 몸통을 제자리로 옮기는 보정값 `dx` 를 프레임 정보 5번째 값으로 넣었다.

### 2. 애니메이션별 프레임 수가 서로 다른 경우 지원

- 애니메이션마다 프레임 수가 4, 6, 4, 8, 6개로 다르다.
- 프레임 수를 코드에 고정하지 않고, 한 바퀴가 끝났는지를 항상 **지금 애니메이션의 `len(frames)`** 로 판단한다.
  그래서 표에 프레임을 더하거나 빼기만 해도 5회 반복과 정지가 그대로 맞게 동작한다.
- 애니메이션마다 프레임 시간(속도)도 따로 지정한다.
